# Деректерді интеллектуалды талдау

Қазақ тіліндегі интерактивті электрондық оқулық. Автор — Оспан Әсел Ғалымжанқызы, PhD, доцент-зерттеуші, әл-Фараби атындағы ҚазҰУ, Жасанды интеллект және Big Data кафедрасы.

Оқулық бакалавриат студенттеріне арналған. Алдын ала дайындық — Python негіздері.

- 15 дәріс және қадамдап ойнатылатын 15 сызба.
- Әр дәрістен кейін түсіндірмесі бар 6 сұрақ. Барлығы 90 сұрақ.
- 15 зертханалық жұмыс және 15 орындалатын Jupyter Notebook.
- `groupby` бейнесабағы, сенімділік аралығы мен жіктеу шегінің интерактивті үлгілері.
- Тақырып бойынша іздеу, браузерде оқу барысын сақтау және `football.csv` оқу деректері.

## Жинақты ашу

1. ZIP архивін толық ашып, қалталардың орналасуын сақтаңыз.
2. `index.html` файлын JavaScript қосылған браузерде ашыңыз.
3. Зертханалық жұмысты орындау үшін Python ортасында `python -m pip install -r requirements.txt` пәрменін іске қосып, жоба түбірінен `jupyter lab` ашыңыз.
4. `notebooks/lab_XX.ipynb` файлын таңдап, ұяшықтарды ретімен орындаңыз. `data/football.csv` оқу деректерімен жұмыс істейтін ноутбуктар файлды сол қалтадан оқиды. Нәтижелер зертханалық нұсқаулықта көрсетілген `work_results/` ішіне жазылады.

HTML, сызбалар, тесттер және бейнесабақ архивтен ашылғанда интернетсіз жұмыс істейді. Python кітапханаларын алғаш орнатуға интернет қажет болуы мүмкін.
